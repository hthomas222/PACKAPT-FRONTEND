PackAPT
Update Packages

Purpose

PackAPT lets you selectively update Ubuntu packages. Only packages that appear in both your approved list (packages.txt) and the currently upgradable list will be shown and can be updated.

How to use

1. Click Pull to refresh the list of upgradable packages.
2. Click Results to see the intersection with your approved list.
3. Go to Update Packages to install a single package or all of them.
